BandControl for REAPER

Control REAPER from the band's phones

Playback, setlist, input and front of house levels and a personal in-ear mix for every band member, over Bluetooth.

For REAPER {{reaper_min}} and newer on Windows, macOS and Linux · Android app

{{icon:download}}Download {{icon:wrench}}Install {{icon:github}}GitHub{{icon:star}}

How it works

  • The extension runs in REAPER. On a Mac it comes with a small menu bar app that does the Bluetooth part, since macOS doesn't let REAPER use Bluetooth.
  • Every band member installs the app and pairs it once with a QR code from REAPER or from a bandmate's phone. It connects to the computer over Bluetooth.
  • The app shows what the project has, by its folder names: songs (regions), inputs, front of house outputs and in-ear mixes. See organizing the project.

Set up

  1. Install the extension on the computer running REAPER: quit REAPER, run the installer for your platform (on Linux copy the library, see below) and start REAPER again.
  2. Install the app on every phone: open the APK on the phone and allow installing from your browser or file manager when Android asks. A phone that has it shows a QR code for the download in its menu (About & share the app).
  3. Pair: in REAPER run the action BandControl: Show pairing QR code (Actions → Show action list; on a Mac also in the BandControl menu bar icon's menu). A window shows the QR code (resize it and the code grows); scan it with the app, or type the code below it.
  4. Pair the rest of the band from the first phone: menu → Share pairing with another phone.

Platform notes

{{icon:windows}}Windows

Windows 10 (1803) or newer with a Bluetooth adapter that supports the peripheral role (BandControl: Show status says when it doesn't). The installer works without administrator rights and installs into %APPDATA%\REAPER; for a portable REAPER choose its folder. Use the ARM installer only with REAPER's ARM64EC build; an x64 REAPER running on an ARM PC needs the x64 one. Uninstall from Settings → Apps.

Until releases are signed, SmartScreen asks first: More info → Run anyway.

Manual install: copy reaper_bandcontrol-windows-x86_64.dll (or the ARM64EC one) into REAPER's UserPlugins folder (Options → Show REAPER resource path) and restart REAPER.

{{icon:apple}}macOS

macOS {{macos_min}} or newer, Apple silicon or Intel. The installer puts the extension and the BandControl app into your home folder; REAPER starts that small menu bar app for Bluetooth, which macOS doesn't let REAPER use itself.

The releases aren't signed by Apple yet, so macOS blocks the installer the first time. Install it in one of these two ways:

Option 1: the installer (recommended)

macOS 15 Sequoia and newer:

  1. Double-click bandcontrol-macos.pkg; it says Not Opened: click Done.
  2. System Settings → Privacy & Security, scroll down, Open Anyway.
  3. Open Anyway again, Touch ID or password, then the installer.

macOS 11 to 14: right-click the package, Open, Open again, then the installer.

Option 2: the Terminal (advanced)

Downloads and installs for your user, without System Settings or a password:

cd ~/Downloads
curl -fLO {{repo}}/releases/latest/download/bandcontrol-macos.pkg
installer -pkg bandcontrol-macos.pkg -target CurrentUserHomeDirectory

Then start REAPER and click Allow when macOS asks whether BandControl.app may use Bluetooth. Its menu bar icon is three faders; if a MacBook's notch hides it, ⌘-drag it to the right, or use BandControl: Show pairing QR code in REAPER.

Manual install: the .dylib into REAPER's UserPlugins folder, BandControl-macos.zip unzipped into ~/Applications, then once: xattr -dr com.apple.quarantine ~/Applications/BandControl.app and the same for the .dylib.

{{icon:linux}}Linux

x86_64 or aarch64 with glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and newer) and BlueZ (bluetoothd), the standard Linux Bluetooth stack. Copy the .so for your architecture into ~/.config/REAPER/UserPlugins and restart REAPER. The adapter is powered on automatically.

{{icon:book-open}}REAPER versions

REAPER {{reaper_min}} or newer. Every release from {{reaper_min}} (the oldest REAPER for Linux still available) to {{reaper_tested}} passes the end-to-end tests, and every change is tested against the oldest and the newest. The extension only uses REAPER functions that are older than that; Windows and macOS use the same ones.

{{icon:android}}Android

Android 9 or newer with Bluetooth LE. The app asks for the Nearby devices permission (on Android 11 and older: location, which Android requires for Bluetooth scanning) and for the camera only when you scan a QR code. Google Play services are not needed; it works on de-Googled phones such as LineageOS.

Pairing, names and where they are saved

  • The pairing code is saved in REAPER's settings, the same for every project. BandControl: Reset pairing key makes a new one and unpairs every phone.
  • Phones show the computer's name; BandControl: Set the name shown on phones changes it.
  • The app remembers every computer it was paired with and connects to the one in range. The menu switches between them or forgets one.

Organizing the REAPER project

BandControl reads your project by its folder names. Three folders decide what shows up in which tab:

INPUTS/             → Inputs tab: one track per input
FOH OUT/            → FOH tab: front of house, feeds to the house desk or the PA
IEM OUT/            → IEM tab: one mix per musician, a hardware output receiving what they want to hear
  • Songs are regions that don't overlap. Markers inside a region are the song's parts for previous / next. Markers are optional.
  • Inputs: the tracks in a top level folder with the word Input or Inputs in its name, in any case.
  • FOH (front of house: what the audience hears, through the house desk or straight to the PA): the tracks in a top level folder with the word FOH or PA in its name.
  • In-ear mixes: tracks with a hardware output and receives, in a folder with IEM or Monitor in its name. The IEM tab sets the mix's volume and the volume and mute of every receive.

Other tracks (click, backtracks, buses) can be anywhere outside these folders. Without the folders the Inputs and FOH tabs are hidden and the IEM tab lists every track with a hardware output and receives.

Troubleshooting

  • Windows warns about the installer: the releases aren't signed yet. More info → Run anyway.
  • macOS says the installer was "Not Opened": same reason, see macOS for the two ways around it.
  • Bluetooth doesn't work: run BandControl: Show status in REAPER, it says why (the adapter is off or can't act as a Bluetooth device, a missing permission, …).
  • The phone doesn't find the computer: is REAPER running? After Reset pairing key every phone has to scan the new QR code.
  • No BandControl icon in the Mac's menu bar: a MacBook's notch hides it when REAPER's menus are long. Hold ⌘ and drag it to the right, or run BandControl: Show pairing QR code.
  • Still stuck? Open an issue with the output of Show status.

Verifying downloads

Each release has a SHA256SUMS file signed with the project's key (public key):

gpg --import signing-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS
