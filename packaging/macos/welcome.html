This installs BandControl for REAPER, so the band's phones can control playback and in-ear mixes over Bluetooth:

  • the REAPER extension, into ~/Library/Application Support/REAPER/UserPlugins, REAPER's usual resource folder (for a portable REAPER, copy reaper_bandcontrol.dylib into its UserPlugins folder instead);
  • the BandControl app, into ~/Applications. macOS doesn't let REAPER itself use Bluetooth, so REAPER starts this small menu bar app, which talks to the phones for it.

Quit REAPER before you continue.
