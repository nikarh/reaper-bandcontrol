### Features

- **proto:** Protobuf schema, framing, crypto and sans-IO sessions
- **core:** Domain model, Daw trait, sync engine and fake DAW
- **server:** Session loop with TCP and BlueZ BLE transports, TCP test client
- **bandctl:** Simulator with control port, test client and pairing QR
- **reaper:** Add REAPER extension with FFI bindings, ReaperDaw and pairing actions
- **android:** Kotlin protocol core with Wire, session, state selectors and TCP link
- **android:** Compose app with BLE/TCP transports, Control and Mix tabs, phone e2e tests
- **android:** Expose receive mute as an accessible switch
- **harness:** Optional fixed web interface port
- **server:** BLE peripheral backends for macOS (CoreBluetooth) and Windows (WinRT)
- **android:** Scan the pairing QR code in the app
- Track folders and level meters in the protocol, simulate project files
- **android:** Track groups from folders, meter subscriptions and peak holds in core
- **android:** DB faders, flat mix layout, Inputs and PA level tabs
- **android:** Compact bottom tab bar
- **android:** QR scanner with CameraX and ZXing instead of Google Play services
- **android:** Tabs Playback, Inputs, PA, IEM
- **android:** Explain connection problems in plain words instead of exception names
- **android:** Share the pairing with another phone as a QR code
